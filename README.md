# 📅 CV & Deep Learning Conferences and Summer Schools

A curated, continuously updated tracker of the **top conferences and summer schools in computer vision, deep learning and machine learning** — dates, locations and deadlines, each checked against the event's official website.

- 🗂️ **Data lives in YAML** — [`data/conferences.yaml`](data/conferences.yaml), [`data/summer-schools.yaml`](data/summer-schools.yaml)
- 🤖 **Tables below are generated** by [`scripts/build.py`](scripts/build.py) — don't edit them by hand
- 📆 **Subscribe to the calendar** — add the raw URL of [`calendar.ics`](calendar.ics) to Google Calendar / Outlook / Apple Calendar ("From URL") to get every event and deadline
- 🔔 **Stays current year on year** — a monthly GitHub Action opens an issue listing next editions to add, TBA fields to fill and broken links

> ⚠️ Deadlines move. Always confirm on the official site (the **source** link in each row) before you submit or apply.

## What gets listed

**Conferences** — the flagship venues: CVPR, ICCV, ECCV, NeurIPS, ICML, ICLR, plus strong CV/AI venues (WACV, BMVC, 3DV, ACCV, AAAI, IJCAI).
**Summer schools** — long-running international schools with competitive selection or a strong lecturer line-up.

Want something added? Open an issue with the official link.

## Updating the data

1. Edit the relevant entry in `data/*.yaml` — add a new item under `editions` for a new year.
2. Use `null` for anything not yet published. **Never guess a date.**
3. Set `verified_from` to the official page you checked.
4. Run `pip install -r requirements.txt && python scripts/build.py` (or just push — the Action regenerates the README).

See [CONTRIBUTING.md](CONTRIBUTING.md) for the full schema.
